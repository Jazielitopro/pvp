# Parryhook UI Redesign Importer

This local Figma development plugin imports the Parryhook Figma-first starter
boards into six ordered pages. It does not make network requests and it does not
touch Luau files. The generated plugin UI embeds the SVG boards, so the importer
does not need a file picker after registration.

## Refresh Embedded Boards

Run `embed-boards.ps1` after changing any SVG starter board. It regenerates
`ui.html` from `ui.template.html`.

## Run In Figma Desktop

1. Create a blank Figma Design file and rename it `Parryhook UI Redesign`.
2. Open `Plugins > Development > Import plugin from manifest...`.
3. Select `docs/ui-redesign/figma-plugin/manifest.json`.
4. Run `Plugins > Development > Parryhook UI Redesign Importer`.
5. The import starts automatically. Use `IMPORT AGAIN` only when you need to
   refresh the generated nodes.

The importer creates:

- `00 Benchmark`
- `01 Foundations`
- `02 Components`
- `03 Desktop`
- `04 Mobile`
- `05 Handoff`

Rerunning the plugin replaces only the nodes generated by this importer, so
manual edits and annotations elsewhere in the file are preserved.
